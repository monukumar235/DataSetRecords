JSON Dataset API – Spring Boot

A Spring Boot backend service to handle JSON dataset records with Insert, Group By, and Sort By operations.

Features

Insert JSON records dynamically into datasets

Query dataset with group-by operator

Query dataset with sort-by operator (ascending/descending)

Data persisted in a relational database (MySQL / Postgres / H2)

Centralized exception handling with @ControllerAdvice

JUnit tests for service and controller layers

REST compliant APIs (testable via Postman)



Tech Stack

Java 17

Spring Boot 3.x

Spring Data JPA

MySQL (default) / H2 for testing

Jackson (for JSON parsing)

JUnit + Mockito
